# مصادر أصول المصاحف

يُحدَّث مع كل طبعة تُضاف. المنتج تجاري، فالترخيص شرط دخول لا تفصيل لاحق.

## مُدمَج

### `hafs-kfqc` — مصحف المدينة النبوية، حفص عن عاصم

| | |
|---|---|
| الناشر | مجمع الملك فهد لطباعة المصحف الشريف |
| مصدر الصفحات | https://github.com/quranpedia/quran-svg — `mushafs/hafs/kfqc/svg` |
| الصيغة | SVG متجهي، ٦٠٤ صفحة، ~٥٢٠ ك.ب للصفحة |
| طبقة الآيات | مضمَّنة في الـSVG (`ayahPolygon`) — Quranpedia، **CC0 1.0** |
| شروط الناشر | استخدام حرّ يشمل النشر الرقمي والمواقع والبرمجيات؛ القيد على **البيع المطبوع** تجاريًّا |
| تاريخ الحصول | ٢٠٢٦-٠٨-١٧ |
| التحقّق | ٦٢٣٦ مضلّعًا = عدد آيات القرآن بالضبط · ١١٤/١١٤ سورة · صفحة ١٠٥ فيها النساء ١٧١–١٧٥ مطابقةً لبياناتنا النصّية المستقلّة |

### `warsh-kfqc` — مصحف المدينة النبوية، ورش عن نافع

| | |
|---|---|
| الناشر | مجمّع الملك فهد لطباعة المصحف الشريف |
| مصدر الصفحات | https://github.com/quranpedia/quran-svg — `mushafs/warsh/kfqc/svg` |
| الصيغة | SVG متجهي، ٦٠٤ صفحة، ٣٢٧ م.ب |
| طبقة الآيات | مضمَّنة في الـSVG (`ayahPolygon`) — Quranpedia، **CC0 1.0** |
| العدّ | مدني — ٦٢١٤ آية، مستخرَجة من الأصل لا مفترضة |
| شروط الناشر | كشروط حفص: استخدام رقمي حرّ، والقيد على البيع المطبوع |
| تاريخ الحصول | ٢٠٢٦-٠٨-١٩ |
| التحقّق | ٦٢١٤ مضلّعًا · ١١٤/١١٤ سورة · لا آية مكرّرة ولا فجوة · ٥١٠ من ٦٠٤ صفحات تُقسّم الآي كما يقسّمها حفص، و٩٤ تفترق |

مصفوف مع حفص على تخطيط ٦٠٤ صفحات: كل صفحة فيه هي كلمات الصفحة نفسها في حفص —
تحقّقنا من ذلك على الصفحات الـ٦٠٤ كلّها مقابل أصول حفص ومقابل `hafs_smart_v8.json`.

### `qalun-kfqc` — مصحف المدينة النبوية، قالون عن نافع

| | |
|---|---|
| الناشر | مجمّع الملك فهد لطباعة المصحف الشريف |
| مصدر الصفحات | https://github.com/quranpedia/quran-svg — `mushafs/qalon/kfqc/svg` (المصدر يكتبها `qalon`) |
| الصيغة | SVG متجهي، ٦٠٤ صفحة، ٢٨٦ م.ب |
| طبقة الآيات | مضمَّنة في الـSVG (`ayahPolygon`) — Quranpedia، **CC0 1.0** |
| العدّ | مدني — ٦٢١٤ آية، **مستخرَجة من أصول قالون نفسها** |
| شروط الناشر | كشروط حفص وورش |
| تاريخ الحصول | ٢٠٢٦-٠٨-١٩ |
| التحقّق | ٦٢١٤ مضلّعًا · ١١٤/١١٤ سورة · لا تكرار ولا فجوة · لا صفحة ناقصة |

كون قالون وورش روايتين عن نافع سببٌ للفحص لا للافتراض. والمقيس من الأصل: آخر آية
في السور الـ١١٤ كلّها تطابق ورشًا، وتخالف حفصًا في ٥٠ سورة؛ وكل صفحة من الـ٦٠٤
تحمل قائمة الآيات نفسها التي تحملها صفحة ورش بالرقم نفسه؛ وأول مضلّع في صفحة ١
يقع حيث يقع في ورش لا حيث يقع في حفص، فالبسملة غير معدودة. فالنقل بين قالون وورش
هويّة لا تحويل، وبين قالون وحفص تحويلٌ كتحويل ورش تمامًا.

| | |

| تاريخ الحصول | ٢٠٢٦-٠٨-١٩ |
| التحقّق | ٦٢١٨ مضلّعًا · ١١٤/١١٤ سورة · لا تكرار ولا فجوة · ٤٤ سورة تخالف حفصًا و١١ تخالف ورشًا |

الدوري روى عن أبي عمرو البصري وعن الكسائي، والاسم وحده لا يفصل؛ الأصل يفصل:
عدّه ليس الكوفي (وهو ما كان يحمله مصحف الدوري عن الكسائي) ولا أيًّا من المدنيَّين.
اسم العدّ في السجلّ (`basri`) وصفٌ للجدول المقيس لا دعوى، والتفصيل في `PROVENANCE.md`.

واحد وأصلان مختلفان وقراءتان مختلفتان.

## مرشَّح — غير مُدمَج

### `qalon/libya-awqaf` — قالون، وزارة الأوقاف الليبية

**مستبعَد.** المصدر ينصّ على الاستخدام **غير التجاري** فقط، والتجاري يحتاج موافقة كتابية
مسبقة. لا يُدمَج قبل إذن صريح.

### `hafs-shamarly` — مصحف الشمرلي، حفص  ✔ مُدمَج جزئيًّا (ترقيم بلا صور)

| | |
|---|---|
| الناشر | مطبعة الشمرلي |
| ما نملكه | **الترقيم وحده**: ٥٢١ صفحة مرقّمة من ٢ إلى ٥٢٢، وتخطيط أسطرها |
| مصدره | `public/mushaf-shamarly.json` — من قاعدة بيانات صفحات قدّمها المالك: أرقام الصفحة والسورة والآية |
| صور الصفحات | **لا شيء** — لا مصدر مرخَّص بعد |
| العدّ | كوفي — ٦٢٣٦ آية، كعدّ مصحف المدينة تمامًا |
| البناء | `npm run mushaf:index-pages hafs-shamarly public/mushaf-shamarly.json` |

حفص هو حفص: هذا الكتاب يعدّ الآي كما يعدّها مصحف المدينة. المختلف — وهو ما يحفظه
الطالب فعلًا — **مواضع انتهاء الصفحات**. فسُجّل بوصفه طبعة على قوّة ترقيمه وحده،
وتعرضه الطبقة النصّية سطرًا بسطر إلى أن تأتي صفحات مرخَّصة، و`pageFormat: 'none'`
يقول ذلك في السجلّ.

وهو **أوّل طبعة خارج مجموعة `kfqc-604`**: صفحته ١٠٦ ليست صفحة ١٠٦ عند المجمّع،
والمحرّك يعلم ذلك (بلا `pageAlignmentGroup`) فلا يفترض تقابلًا.

الباقي له: صور صفحات بترخيص تجاري، وطبقة مناطق (`external-json`) لأنها لن تأتي
معها. **ولا تُستخدم أصول QuranFlash**، ووجود PDF على الإنترنت ليس إذنًا بإعادة نشره.

### `shamarly-hafs` — (الإدخال القديم، للتاريخ)

طبعة أخرى **لنفس الرواية** (حفص)، لا رواية جديدة. غير متاحة في `quran-svg`. تحتاج:

1. مصدر صفحات متجهي أو عالي الجودة **بترخيص يسمح بالاستخدام التجاري**.
2. طبقة مناطق (`external-json`) لأنها لن تأتي جاهزة.

**لا تُستخدم أصول QuranFlash** — قارئ تجاري لا يرخّص صفحاته.

نملك اليوم فهرس صفحات الشمرلي (`public/mushaf-shamarly.json`) مستخرجًا من قاعدة بيانات
قدّمها المالك: ترقيم الصفحات وكسرها داخل الآية وتخطيط الأسطر. **هذا ترقيم لا صور**،
ويصلح للطبقة النصّية ولتوليد المناطق لاحقًا، لا لعرض صفحة حقيقية.

## متاح ولم يُستورد بعد

لم يبقَ في `quran-svg` من طبعات مجمّع الملك فهد شيء: الخمس كلّها مُدمَجة. وأي
طبعة قادمة تمرّ بالمسار نفسه — عدّها يُستخرج من أصلها بـ`mushaf:index`، ويُعلَن
في السجلّ، ويُتحقَّق منه بـ`mushaf:validate`.
